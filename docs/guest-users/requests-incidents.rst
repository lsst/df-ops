Open a SLAC Service Now Ticket
==============================

If you have an incident that cannot be resolved by community discussion channels, please send your issue to usdf-help@slac.stanford.edu.

Report Incident in Slack
========================

The LSST Discovery Alliance Slack contains the #usdf-rac-users channel for discussion of issues with USDF systems. If you need an invitation to this channel, please contact Adam Bolton or Sierra Villarreal. This channel is intended for resolving issues that can be handled via community input.

In the event that Slack is down email and Zoom will be used.
