Architecture
============

weatherbroadcaster is a FastAPI application built with Safir.
The web application serves cached Rubin Observatory weather station data from ``GET /weatherbroadcaster/data``.

A Kubernetes CronJob refreshes the cache periodically by querying the ``usdf_efd`` EFD and writing a MeteoBlue-compatible JSON payload.
The application and update job use the same container image and share the ``WEATHERBROADCASTER_`` configuration prefix.

Data Flow
=========

The update job queries the most recent hour of EFD data for temperature, relative humidity, wind, dew point, and rain rate from ESS SAL topics with ``salIndex=301``.
It writes the resulting JSON cache to the configured weather data file path, which defaults to ``/data/weather.json``.

The API validates and returns the cached file from ``GET /weatherbroadcaster/data``.
If the cache has not been created, the endpoint returns ``503 Service Unavailable``.

Dependencies - S3DF
===================

* USDF EFD, using the ``usdf_efd`` EFD client configuration.
* Rubin Science Platform ingress and Gafaelfawr routing.
* Phalanx and Argo CD for Kubernetes deployment.

Dependencies - External
=======================

MeteoBlue consumes the published weather data format.

Disaster Recovery
=================

The service can be redeployed from Phalanx.
The cached weather data is regenerated by the update job from EFD data, so recovery depends on successful deployment and EFD availability.
